# 💪 프로젝트 개요

사용자가 구매한 로또와 당첨로또와의 비교 후 수익률을 산출하는 프로그램

# 📝 구현 기능 목록

### 구입 안내 메시지를 출력하는 기능

    - [x] '구입금액을 입력해 주세요.'를 출력한다.

### 사용자의 로또 구입 금액을 입력받는 기능

    - [x] 사용자의 로또 구입 금액을 입력받는다.
        - [x] 1000원으로 나눠 떨어지지 않는 경우엔 에러메시지를 출력하고 다시 입력받는다.

### 로또 구매 결과를 출력하는 기능

    - [x] 'x개를 구매했습니다.' 식으로 사용자의 구매 갯수에 따른 메시지를 출력한다.
    - [x] 로또 번호를 오름차순으로 출력한다.

### 당첨 번호 입력 안내 메시지를 출력하는 기능

    - [x] '당첨 번호를 입력해 주세요.'를 출력한다.

### 당첨 번호를 입력받는 기능

    - [x] 당첨 번호를 입력받는다.
        - [x] 당첨 로또 번호가 6개를 넘어가면 에러메시지를 출력하고 다시 입력받는다.
        - [x] 당첨 로또 번호에 중복되는 숫자가 있으면 에러메시지를 출력하고 다시 입력받는다.

### 보너스 번호 입력 안내 메시지를 출력하는 기능

    - [x] '보너스 번호를 입력해 주세요.'를 출력한다.

### 보너스 번호를 입력받는 기능

    - [x] 보너스 번호를 입력받는다.

### 당첨 통계를 출력하는 기능

    - [x] '당첨 통계
          ---' 메시지를 출력한다.
    - [x] 일치 결과별 결과를 출력한다.

### 수익률을 출력하는 기능

    - [] '총 수익률은 x.y%입니다.'식으로 출력한다.
