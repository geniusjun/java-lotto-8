# 💪 프로젝트 개요

사용자가 구매한 로또 번호와 직접 입력한 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하는 로또 게임입니다.

# 📝 구현 기능 목록

### 로또 구입금액 안내 문구 출력 기능

    - [x] '구입금액을 입력해 주세요.'를 출력한다.

### 로또 구입 금액 입력 기능

    - [x] 로또 구입 금액을 입력받는다.
        - [x] 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외가 발생한다.

### 로또 구입 내용 출력 기능

    - [] '(로또 구매 개수)개를 구매했습니다'를 출력한다.
    - [] 구매한 로또 내용을 출력한다.

### 당첨 번호 안내 문구 출력 기능

    - [x] '당첨 번호를 입력해 주세요.' 를 출력한다.

### 당첨 번호 입력 기능

    - [] 당첨 번호를 입력받는다.
        - [] 로또 번호의 개수가 6개가 넘어가면 예외가 발생한다.
        - [] 로또 번호에 중복된 숫자가 있으면 예외가 발생한다.

### 보너스 번호 안내 문구 출력 기능

    - [] '보너스 번호를 입력해 주세요.' 를 출력한다.

### 보너스 번호 입력 기능

    - [] 보너스 번호를 입력 받는다.

### 당첨 통계와 수익률 출력 기능

    - [] 당첨 통계를 형식에 맞게 출력한다.
    - [] 수익률을 출력한다.
